# Test cases

## Fields

1. Summary: a short summary about the test case, it seems like to be the name of the test case. Text field
2. Project: a test case belongs to a project or none. Selection field.
3. Categroy: a test case belongs to zero or multiple categories. Selection field, multiple choices.
4. Priority: priority of the test case, 5 levels: HIGHEST, HIGH, MEDIUM, LOW, LOWEST. Selection field.
5. Automated: true or false. Toggling field.
6. Description: detail information of the test case. A user can choose a Test Case Template to auto gegerate the content for description so that they edit or update for more information. Text area.
7. Notes: Note for this test case. Text area.
8. Script: the automation script that run this test case. Text field.
9. Arguments: arguments for script. Text field.
