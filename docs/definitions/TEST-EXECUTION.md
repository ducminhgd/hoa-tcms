# Text execution

The act or result of running one test case during a test run

## Fields

1. Name of the test execution, required, text field.
2. Tester: selection of user, multiple choices.
3. Test run: choose a test run to import test cases.
4. List of "Test case result": generated by the information of tests cases, with additional fields: result, attached files, logs.

### Test case result

1. Clone most of the fields of the test cases.
2. Has result field: IGNORE, FAILED, PASS, NOT TESTED, WARNING. Default `NOT TESTED`.
3. Has attached files section.
4. Has logs text area for custom logs.

## List of test cases to run

User can add test cases into the test run. And, test execution will execute the cases, the test result has its status in this execution: IGNORE, FAILED, PASS, NOT TESTED, WARNING. Default `NOT TESTED`.
The result of the test case in this test execution does not effect its result in other test executions.
