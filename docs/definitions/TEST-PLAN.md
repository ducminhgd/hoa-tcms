# Test plan

## Fields

1. Name: text field. Required
2. Project: select field. Multiple choices. Required
3. Version: version of the build, default "UNSPECIFIED"
4. Type: type of the test. Enum values: ACCEPTANCE, FUNCTIONAL, API, INTEGRATION, PERFORMANCE, REGRESSION, SECURITY. Multiple choices, selection field.
5. Description: plan detail. Text editor.
6. Status: TO DO, IN PROGRESS, DONE, CANCEL. Single selection field. Required, default TO DO.
